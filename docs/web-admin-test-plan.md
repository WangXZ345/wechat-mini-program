## 2. 登录与会话测试

- 合法四种管理员角色可以登录并获得最小 profile。
- 普通 `user`、不存在账号、disabled、inactive、非法/缺失 role 均拒绝。
- 错误账号和错误密码返回相同 `INVALID_CREDENTIALS`，不枚举账号。
- 密码 hash 使用随机盐；相同密码的两条记录 hash 不相同。
- 5 次/5 分钟失败触发账号限流，IP 级阈值和 `Retry-After` 生效；函数冷启动/多实例不重置。
- Access 过期后只刷新一次；refresh 轮换，旧 refresh 重放触发 family 撤销。
- 退出登录、管理员主动撤销、禁用、角色变更、改密后旧会话失效。
- Cookie 包含 `HttpOnly/Secure/SameSite`，Origin/CSRF 校验有效。
- profile 响应不含 password hash、salt、token、openid、完整手机号。
- 安全日志记录成功/失败/锁定/刷新复用/退出/撤销，不含敏感值。

## 3. 权限测试

对每个路由和 API 使用五种身份执行允许/拒绝矩阵：

### user

- 不能登录、不能读取 profile、不能调用任何 `/api/admin/v1/*`。

### customer_service

- 可处理授权订单、发货和售后。
- 不能修改商品/库存，不能确认付款，不能最终退款。
- 只能看到掩码手机号/地址，不返回付款截图、交易号、客户账款、退款账户。

### finance

- 可审核付款、查看账款、处理已经审核的退款。
- 不能修改商品/库存，不能审核售后，不能跳过售后审核。

### procurement

- 可管理商品、价格、库存、预警、导入、标签、推荐和商品分析。
- 付款、退款、账款、付款截图、完整手机号、完整地址的路由返回 403。
- 即使绕过前端菜单直接请求，响应也不包含敏感字段或敏感同步事件。

### super_admin

- 可访问全部合法模块。
- 超额退款、非法订单状态、库存不足、重复付款/退款仍被领域规则拒绝。

额外测试：篡改前端 role、permissions、openid、sessionId、entity owner 均无效；IDOR 请求其他实体时按权限/归属拒绝。

## 4. 商品同步测试

1. Web 改商品名称，小程序已打开详情在目标 1-3 秒内局部刷新。
2. Web 改售价，小程序列表、详情和购物车价格有效性更新；下单仍用服务端价格。
3. Web 下架商品，小程序不能新增购物车或新下单；旧页面不长期显示可售。
4. 小程序产生销售数据后，Web 商品分析局部更新。
5. 同一毫秒 100 条商品事件按复合游标无重无漏。
6. 采购可见商品/库存字段，其他角色只获得职责所需投影。

## 5. 库存同步测试

1. Web 人工调整库存，另一个 Web 窗口自动更新。
2. 小程序订单审核通过扣库存后，Web 库存和预警更新。
3. 重复事件、重复 `Idempotency-Key`、刷新重试不会重复扣库存。
4. 两管理员以相同 `expectedVersion` 调整，只有一方成功，另一方得到 `DATA_VERSION_CONFLICT`。
5. 普通用户、客服、财务始终看不到真实库存。
6. 批量导入使用批次/合并事件，不产生每商品全站刷新风暴。

## 6. 订单同步测试

1. 小程序提交订单，Web 订单列表目标 1-3 秒内出现。
2. Web 审核订单，小程序订单详情更新。
3. Web 拒绝/取消订单，小程序显示正确状态。
4. 同一订单并发审核只有一次库存与账款副作用。
5. 重复 `Idempotency-Key` 返回原成功结果；同键不同请求返回 409。
6. 旧订单和旧字段兼容，状态语义不改变。
7. 分页使用稳定游标，新增订单期间翻页不重复/漏项。

## 7. 付款与账款同步测试

1. 小程序上传付款凭证，Web 财务待办出现。
2. Web 确认付款，小程序付款状态更新。
3. 重复确认不会重复生成 `payment_records` 或 `account_logs`。
4. Web 只提交整数 `paidAmountCents`；篡改订单金额或付款状态被拒绝。
5. 采购/客服不能读取付款截图、交易号、账款或付款事件。
6. 线下凭证保持 `pending_confirm`，不得被前端直接显示为到账。
7. 批次付款和客户账款汇总与旧小程序结果一致。

## 8. 发货同步测试

1. Web 填写物流并确认发货，小程序订单物流更新。
2. 合并发货后关联订单同步显示同一合法物流信息。
3. 重复确认、重复事件不会重复发货或重复日志。
4. 客服只能查看/修改职责内地址投影，采购不返回完整地址。
5. 并发修改物流信息触发 version 冲突并重新确认。

## 9. 售后退款同步测试

1. 小程序提交售后，Web 客服待办出现。
2. Web 客服审核后，小程序状态更新。
3. 财务只能处理已审核退款，处理后小程序显示结果。
4. 重复事件/请求不会重复退款、重复恢复库存或重复冲账。
5. 退款金额超过上限、状态不合法、前端篡改金额均拒绝。
6. 客服不见退款账户；采购不见售后退款敏感数据；财务不能审核售后。

## 10. 冲突测试

- 商品改价、上下架、人工库存、订单备注、发货信息、售后审核分别执行双管理员并发。
- 验证 `expectedVersion` 只允许一个更新，冲突响应不泄露敏感字段。
- 库存扣减、付款、退款使用事务 + 状态守卫 + 业务键，不只依赖 version。
- 云函数超时后客户端重试，最终结果可确认且无重复副作用。

## 11. 断网与重连

- Web 断网期间小程序创建订单；恢复后按 cursor 补齐。
- 小程序断网期间 Web 改价/发货；恢复后得到最新状态。
- Wi-Fi/移动网络切换、浏览器后台/睡眠、页面 reload、watch error 均能恢复。
- cursor 过期返回 `CURSOR_EXPIRED`，按模块刷新并重设 high watermark。
- 重复投递不触发业务写，无同步循环。
- 多标签页、多设备 cursor 与失效通知不相互覆盖身份。

## 12. 性能测试

### Web 指标

- 登录页和工作台首屏目标 2 秒内可用（测试网络条件需记录）。
- 普通列表操作 300ms 内有视觉反馈。
- 搜索 debounce 250-350ms。
- 列表分页，图片懒加载，图表按路由加载，不一次取全部订单。
- 在 1366x768、1440x900、1920x1080 和平板横屏检查无重叠、溢出或遮挡。

### API/同步指标

- 测试 1/10/50 在线客户端和 1/10/100 events/s。
- 记录事件 API、详情 refetch 和关键列表的 P50/P95、错误率、函数冷启动和查询扫描量。
- 记录同步端到端 P50/P95、超过 3 秒比例、合并刷新次数。
- 检查数据库索引命中、函数内存/超时、事件积压和清理耗时。

性能目标是验收门槛，不在未连接测试环境时标记通过。

## 13. 安全测试

- 未登录、过期、撤销、disabled、非法 role 会话全部拒绝。
- CORS 只允许测试域；CSRF、Origin、Cookie 属性、CSP 和点击劫持保护有效。
- XSS 字符串在表格、抽屉、日志和错误中按文本渲染。
- 上传校验 MIME、扩展名、大小、数量，拒绝脚本和超限文件。
- SSRF/路径遍历/CSV formula injection 在导入导出路径受控。
- API 不接受浏览器 actor/role/openid；`_callerOpenid` 在 Web 路径无效。
- 直接数据库读取/写入 `sync_events` 和业务集合被规则拒绝。
- 事件、日志、构建产物、source map 和环境变量不含密码、token、密钥、完整 PII。
- 登录限流、会话复用检测、管理员状态变更即时失效。

## 14. 业务回归

小程序至少回归：登录、商品搜索/详情、购物车、提交订单、订单列表/详情、取消、付款凭证、物流、售后、退款状态、地址和手机号。后台旧入口至少回归商品/库存/导入、订单审核、付款、发货、售后、退款、账款和权限。

每个共享 service 迁移先跑旧入口 contract snapshot，再开放 Web 写操作。未迁移模块保持旧实现，不改业务语义。
