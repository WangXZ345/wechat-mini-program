## 二、各页面内容摘要

### 1. 隐私保护指引

涵盖内容：
- **信息收集和使用**：账号信息、订单交易信息、收货地址、图片文件、搜索使用记录、后台操作信息
- **信息共享**：不出售用户信息，仅在必要情况下共享
- **用户权利**：查看、修改、删除个人信息的权利
- **信息安全**：角色权限管理、敏感字段脱敏
- **未成年人保护**：需监护人指导使用
- **联系方式**：提供完整的联系途径

### 2. 用户协议

涵盖内容：
- **服务说明**：商品浏览、购物车、订单管理、付款、发货、售后等服务
- **用户资格与账号管理**：信息真实性要求、账号安全责任
- **商品信息**：库存以后台审核为准、价格可能变化
- **订单规则**：提交订单不等于订单成立，需审核确认
- **付款规则**：线下付款方式、财务确认流程
- **发货与自提**：发货时间受多因素影响
- **售后规则**：需人工审核、退款不超过实付金额
- **用户禁止行为**：恶意下单、虚假付款、冒用信息等
- **责任限制**：不可抗力、第三方原因等免责条款
- **争议解决**：适用法律和管辖法院

### 3. 付款说明

涵盖内容：
- **支持的付款方式**：收款码、银行转账等线下付款
- **付款流程**：订单审核 → 付款 → 上传凭证 → 财务核对 → 付款确认
- **付款凭证要求**：必须包含金额、时间、收款方、交易状态
- **财务确认规则**：上传凭证不等于付款成功、金额核对、凭证异常处理
- **异常情况处理**：金额不一致、重复付款、截图错误、未到账、订单取消等
- **付款时效**：提醒及时付款
- **注意事项**：核对收款方、保留凭证、不向非官方账号付款

### 4. 售后规则

涵盖内容：
- **可申请售后的情况**：错发、少发、破损、质量异常等
- **售后申请要求**：详细原因、商品凭证、订单信息
- **售后审核流程**：提交 → 人工审核 → 审核结果 → 后续处理
- **退款规则**：需审核通过、金额限制、不支持自动退款
- **退货规则**：退货要求、验货确认、库存恢复
- **售后时效**：建议及时申请
- **不支持售后的情况**：已标注瑕疵、主观不喜欢、恶意售后等
- **注意事项**：如实填写、保留凭证、不重复提交

### 5. 瑕疵商品说明

涵盖内容：
- **瑕疵商品定义**：外包装瑕疵、临期商品、特殊批次等
- **重要说明**：不包括过期、质量不合格、安全隐患商品
- **购买提示**：瑕疵标注位置、下单前检查、价格库存差异
- **售后边界**：已标注瑕疵不作为同一售后原因、未标注问题可售后、人工审核
- **库存恢复规则**：验货确认、可售商品恢复库存、不可售商品不恢复
- **特别提示**：适合对外观要求不高的客户、临期商品尽快使用
