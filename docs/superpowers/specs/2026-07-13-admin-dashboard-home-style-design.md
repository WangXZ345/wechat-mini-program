# 后台工作台顶部与商品首页视觉统一设计

## 目标

仅调整小程序后台工作台截图所示的顶部区域，使其与商品首页形成同一套暖中性色产品界面。保留后台工作台现有数据、角色可见范围、时间筛选行为、跳转入口和业务语义。

## 修改范围

- `miniprogram/pages/admin/dashboard/index.wxml`
- `miniprogram/pages/admin/dashboard/index.wxss`

本次不修改其他后台页面、共享业务逻辑、云函数、权限、集合、字段、订单、库存、付款或账款流程。

## 视觉设计

### 页面基底

- 后台顶部使用与商品首页一致的暖米白页面背景 `#F8F4ED`。
- 去除现有大面积棕色渐变、玻璃感叠层和厚重 Hero 阴影。
- 内容表面使用 `#FFFDF9`，边框使用暖棕低透明度颜色，阴影保持轻量。

### 标题与角色信息

- 保留“管理工作台”“工作台”和说明文案。
- “工作台”采用与商品首页“商品”接近的标题层级：52rpx、800 字重、正常字距。
- 角色信息改为标题区右侧的白色实体小卡，视觉语言对应商品首页右侧快捷操作卡。
- 保留当前角色名称，不改变角色数据来源和权限判断。

### 更新时间

- 保留更新时间信息，将其作为次级信息展示。
- 减少多层胶囊堆叠，不与角色信息争夺视觉层级。

### 时间范围

- 保留“今日、近 3 日、近 7 日、近 30 日”和 picker 切换能力。
- 时间选项改为商品首页推荐分类栏的白底分段控件。
- 当前选项使用深棕背景和暖白文字，未选项使用暖白背景和灰棕文字。
- 保留原有 `onRangeChipTap`、`onRangeChange`、`rangeIndex` 和横向滚动行为。

## 交互与响应式

- 点击反馈只调整透明度和轻微缩放，不增加装饰性动画。
- 保留竖屏、横屏和宽屏类名及现有响应式布局。
- 触控区域不小于现有尺寸，避免降低可操作性。
- 不改变加载、空状态、错误状态和后续数据区块。

## 数据、安全与兼容性

- 不新增、删除或重命名任何数据字段。
- 不改变 `adminProfile.roleName`、`updatedAt`、`rangeOptions` 或 `rangeIndex` 的渲染逻辑。
- 不扩大任何角色的数据可见范围，不显示新的敏感信息。
- 不修改 `getAdminDashboardStats` 或其他云函数。
- 旧入口 `pages/admin/dashboard` 和当前入口 `pages/admin/dashboard/index` 均不调整。

## 验收标准

1. 后台工作台顶部不再出现大面积渐变 Hero，整体基底与商品首页一致。
2. 标题、白色操作卡、轻边框、轻阴影和深棕选中态能明确对应商品首页视觉语言。
3. 角色、更新时间和五种时间切换方式均保留且可见。
4. 时间筛选事件、数据刷新、后台权限和后续内容区块不发生行为变化。
5. WXML、WXSS 和相关 JSON/JS 静态检查通过。
6. 微信开发者工具中竖屏显示无溢出，横屏与宽屏布局保持可用。

## 部署边界

- 本次实施范围仅包含小程序前端 WXML/WXSS。
- 不需要上传云函数。
- 修改完成后需要在微信开发者工具中重新编译或预览。
- 未经用户明确要求，不发布小程序。
