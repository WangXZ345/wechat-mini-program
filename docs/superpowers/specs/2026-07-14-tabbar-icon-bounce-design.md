# 底部导航图标轻微回弹设计

## 目标

用户在“商品”“购物车”“订单”“我的”四个底部导航选项之间切换时，新选中的图标播放一次轻微回弹动画，让选中反馈更明确，同时保持当前导航的克制视觉风格和即时切换手感。

## 范围

仅调整现有 `miniprogram/custom-tab-bar/` 组件：

- `index.js`：控制动画 class 的重置与重新触发。
- `index.wxml`：为当前需要播放动画的图标增加状态 class。
- `index.wxss`：定义轻微回弹关键帧和降级规则。

不修改 tab 路由、`wx.switchTab` 调用、购物车角标数据、权限可见性、页面生命周期、云函数或业务字段。

## 交互设计

- 每次页面通过现有 `setSelected(selected)` 同步新选中项时，重置并重新添加动画状态，确保返回已经访问过的 tab 时仍能播放。
- 动画只作用于新选中的 `.tab-icon`，文字、选中背景胶囊和购物车角标保持静止。
- 动画总时长约 `320ms`：图标先向上移动约 `6rpx`，随后轻微回落并恢复到当前选中态的最终位置。
- 动画包含克制的缩放变化，用于形成柔和弹性，但不改变图标长期尺寸和布局空间。
- 点击当前已经选中的 tab 不触发路由切换；沿用现有行为，不额外播放动画。
- 不等待动画结束再执行 `wx.switchTab`，避免增加切换延迟。

## 状态与实现边界

组件增加一个仅用于视图动画的临时状态，记录当前播放动画的 tab 索引。`setSelected()` 先清除该状态，再在 `setData` 回调中设置新索引，使 WXSS 动画可以被重复触发。动画状态不参与路由判断、角标刷新或权限判断。

如存在连续快速切换，后一次 `setSelected()` 覆盖前一次动画状态；最终选中项仍由现有 `selected` 字段决定，不引入新的业务状态源。

## 无障碍与兼容

- 沿用现有 `@media (prefers-reduced-motion: reduce)`，对新增动画 class 明确设置 `animation: none !important`。
- 使用微信小程序 WXSS 支持的 `@keyframes` 和 `transform`，不新增依赖。
- 保持竖屏、横屏和宽屏布局尺寸不变，动画通过 transform 绘制，不触发布局重排。

## 验证

1. 检查 `index.js` 语法。
2. 检查 WXML 动画 class 只绑定到当前选中图标。
3. 检查 WXSS 关键帧最终 transform 与当前 active 图标位置一致，避免动画结束后跳变。
4. 检查四个 tab 的 route、文字、图标结构和购物车角标逻辑未改变。
5. 在微信开发者工具中依次切换“商品 → 购物车 → 订单 → 我的 → 商品”，确认每次只有新选中图标轻微回弹，页面切换无额外等待，角标不随图标跳动。
6. 开启减少动态效果后确认动画被禁用。

## 部署边界

本次仅涉及小程序前端文件。完成实现后需要在微信开发者工具中重新编译或预览；不需要上传云函数，也不包含小程序发布操作。
